# 기록시스템 소개·타이핑 페이지 최종 통합

2026-11-02. 공개 기준 main 2c86f4f 이후 최소 조합. 실제 Record/서버/회원 API·DB·건강 브리지·앱 패키지는 변경하지 않는다.

## 재사용과 신규 조합

- 별도 담당 채팅의 안정본 RecordSystem.jsx, 범위 제한 CSS, 13개 정적 자산을 SHA256 확인 후 재사용했다. 기존 코드가 만든 예시 UI·QR·공식 배지이며 운영 회원 데이터나 쓰기 요청은 없다.
- 이 채팅에서는 공통 메뉴, 초기 SSR/hash 경로, MIME, 별도 HTML/SEO/sitemap을 조합했다. 소스 정상 동작은 유지하고 Record 루트 ID·고정 메뉴 스크롤 여백·비대화형 제목 초점 테두리만 최소 보완했다.
- 메뉴 순서: 기존 5개 → 오시는 길 이후 추가 간격 → 원래 아이콘+800 굵기 타이핑사관학교 → 800 굵기 기록시스템 → 상담예약. 다른 지점에 두 도구를 추가하지 않았다.
- 직접 record-system.html 및 #jeonju/record. 기존 #record의 스파링클럽 리다이렉트는 유지한다. FAQ의 기존 https://app.boxingacademy.pe.kr/record.html 링크도 유지한다.
- iPhone/Android 공식 스토어 배지·QR, 실제 UI 예시 5종, 건강 가져오기/공개 분리와 회원 전용 안내. Record 휴대전화 설치 링크는 차단하지 않고, 타이핑 PC 설치 파일의 휴대전화 차단만 그대로 적용한다.
- 원본 배지는 변형하지 않으며 하단에 Apple/Google 상표 권리 안내를 추가했다. 확인 출처: https://developer.apple.com/app-store/marketing/guidelines/ 및 https://partnermarketinghub.withgoogle.com/brands/google-play/legal-requirements/ . 일반 앱 개발자의 다운로드 배지 사용은 https://developer.android.com/distribute/marketing-tools/brand-guidelines 에서 별도 안내한다.
- 상위 WebUpdateNotice/미저장 협업 초안 보호, 서비스워커, 24시간 자산 호환 보관을 그대로 재사용한다. 공개 후 최종 CI/라이브 확인은 별도 배포 증거에 기록한다.

## 이미지 승인 범위

기존 일반 이미지 지침과 ImageGen·홍보 합성 방식의 충돌을 발견해 게시를 보류하고 소유 채팅에 확인했다. 해당 시안을 보여드린 질문에 대한 인간 사용자의 답변 **“현재 시안 사용 — 이번 페이지에만 예외 허용”**을 read_thread에서 직접 확인했다. 이 승인에 따라 인계받은 hero-desktop.webp/hero-mobile.webp 및 promo-og.jpg/promo-portrait.jpg만 이 소개 페이지에서 사용한다. 공통 지침은 수정·영구 완화하지 않는다. 실제 UI·예시 자료·AI 배경을 구분해 본문에 표시했다.

## 검증과 트래픽

- 소스 12개, 프로덕션 5개(Record HTML/공식 링크/숨은 Home 미장착/정적 자산 해시 포함), 자산 보관 3개 및 SW 7개 시나리오. 16개 기존 화면과 연관 동작 회귀는 최종 실행 증거를 확인한다.
- record-browser.mjs: 320/360/390/768/1440px 넘침·깨진 이미지·제목 2줄 초과 0. 두 설치 배지가 첫 화면 안에 보이고 현재 메뉴 두 탭이 보인다. 키보드 탭, 확대/Escape/초점 복원, 3개 기기 선택, FAQ, hash/뒤로/앞으로, 협업 초안, no-JS 핵심 안내, WebKit을 검사했다.
- typing-browser.mjs: 한국어 연습 크롭 3장, 확정 원고·8개 접기, 3종 모바일 설치 차단, 좁은 터치 Windows PC 허용과 자동 선택을 재검사했다.
- 같은 로컬 HTTP·1440×1000·차가운 컨텍스트·SW 비활성 조건에서 Record 전후: 홈페이지 10요청→10요청, 응답 본문 합 1,637,824B→1,672,024B(+34,200B); 타이핑 11→11요청, 1,055,810B→1,089,834B(+34,024B). 공유 CSS/JS·자산 목록·내부 메뉴 증가분이며 두 페이지에서 Record 이미지 요청은 모두 0, API/DB 요청도 0이다. 압축되지 않은 로컬 본문 합으로 인터넷 회선 전송량/성능을 보장하지 않는다.
- 새 Record 최초 화면은 14요청·1,187,689B·API0이다. 처음에는 프로필+선택한 화면만 그린다. 다른 탭 UI 전체나 홍보 JPG를 숨겨 내려받지 않는다. 실제 최종 수치는 record-page-verification.json을 따른다.
- 디자인 검사 few-pictures 예외: 하나의 승인된 배경과 실제 UI 5종 중 현재 선택한 2종이 보이는 구조이다. 단순 수를 채우려고 다른 UI를 숨겨 미리 내려받거나 무관한 사진·영상/회원 성과를 추가하지 않는다. 기존 브랜드 paper색·글자 크기·가로 지점 메뉴는 유지한 경고이며 실제 폭·선택 메뉴 노출을 별도 검증한다.

## 남은 한계

실제 휴대전화 앱 재설치/회원 로그인/건강 가져오기 및 구형 Safari의 원본 이미지 대체 경로는 이 정적 웹 작업에서 실기 검증하지 않았다. 앱 본체·인증·공개 설정은 바꾸지 않았다. Windows 타이핑 0.1.4는 여전히 게시자 서명과 실제 설치/업그레이드 미검증 시험판이며 안내를 유지한다.
